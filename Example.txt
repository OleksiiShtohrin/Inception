To check FTP services run:

- Check that the FTP container is running:
docker compose -f srcs/docker-compose.yml ps ftp

- Check the FTP service logs:
docker compose -f srcs/docker-compose.yml logs --tail=30 ftp

- Connect to the FTP server:
filezilla

Protocol: FTP — File Transfer Protocol
Host: 127.0.0.1
Port: 21
Encryption: Only use plain FTP (insecure)
Logon Type: Normal
User: ftpuser
Password: from ftp_password.txt

- Check file:
docker exec wordpress ls -l /var/www/html/ftp-test.txt





To check Backup services run:

- Create a backup:
docker compose -f srcs/docker-compose.yml run --rm backup

- Remove containers and data:
make fclean

- Start the project again:
make

- Restore the database:
sudo sh -c 'docker exec -i mariadb sh -c '\''mariadb -u"$MYSQL_USER" -p"$(cat /run/secrets/db_password)" "$MYSQL_DATABASE"'\'' < /home/oshtohri/data/backups/wordpress_your_backup.sql'

- Verify the restoration:
docker exec mariadb sh -c 'mariadb -u"$MYSQL_USER" -p"$(cat /run/secrets/db_password)" "$MYSQL_DATABASE" -N -e "SELECT ID, post_title, post_status FROM wp_posts WHERE post_content LIKE '\''%Test_backup_post%'\'';"'
